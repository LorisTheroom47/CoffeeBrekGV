# Coffee Break — Regole del progetto

## Percorso principale

Tutto il progetto deve rimanere all’interno della cartella:

`Desktop/Coffee Break`

Il codice dell’applicazione si trova esclusivamente in:

`Desktop/Coffee Break/website`

Non creare file del progetto al di fuori della cartella `Coffee Break`.

## Metodo di lavoro

- Analizzare sempre i file esistenti prima di modificarli.
- Modificare solo i file necessari all’obiettivo richiesto.
- Non eseguire refactoring non richiesti.
- Non aggiungere funzionalità non richieste.
- Non installare dipendenze senza esplicita autorizzazione.
- Non eliminare file senza esplicita autorizzazione.
- Non modificare configurazioni globali del computer.
- Non pubblicare online e non effettuare push senza autorizzazione.
- Riutilizzare componenti e funzioni esistenti.
- Evitare codice duplicato.
- Mantenere componenti piccoli, leggibili e riutilizzabili.
- Usare TypeScript in modo rigoroso.
- Mantenere il progetto compatibile con Next.js App Router.
- Conservare testi e interfaccia utente in italiano.
- Eseguire lint e build dopo modifiche rilevanti.
- Segnalare chiaramente errori, dubbi o decisioni tecniche.

## Struttura delle cartelle

- `website`: codice del sito
- `docs`: documentazione del progetto
- `assets`: risorse grafiche originali
- `database`: schemi e migrazioni del database
- `backups`: copie di sicurezza manuali
- `prompts`: prompt utilizzati durante lo sviluppo
- `screenshots`: schermate delle versioni del sito
- `exports`: file esportati

## Regole per i report

Ogni attività deve terminare con un report che indichi:

- obiettivo completato
- file creati
- file modificati
- comandi eseguiti
- risultato del lint
- risultato della build
- problemi o avvisi
- stato finale
